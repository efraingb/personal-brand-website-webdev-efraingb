# **App Name**: Efraín's Digital Stage

## Core Features:

- Hero Section: Hero section showcasing name, a brief, impactful title, and a short professional overview.
- Project Gallery: Interactive project gallery displaying project name, URL, description, and thumbnail.
- Dynamic Status Verification: Dynamically verify if a project URL is active using an external tool and update the display accordingly.
- Project Display: Embed live projects in an iframe within a modal or content area if online; display a project thumbnail and a message if offline.
- Documents/Links Section: Link to books (Before Toasters Rule, Practical Computer Science for Everyone), LinkedIn, and GitHub profiles in a minimal section.
- Contact Section: Simple contact option via mailto:hiefraingb@gmail.com and links to professional profiles like LinkedIn.

## Style Guidelines:

- Primary color: A professional dark blue (#003049), conveying trust and stability.
- Background color: A lighter blue (#D4E7F2), providing a clean and corporate feel.
- Accent color: A vibrant teal (#40A2D8) for interactive elements to signal innovation and guide users.
- Clean, sans-serif font for excellent readability and a professional look.
- Single-page layout with smooth navigation to give off the feeling of interacting with an app.
- Use subtle, elegant microinteractions and animations to enhance UX without being distracting.
